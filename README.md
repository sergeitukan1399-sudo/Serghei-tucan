# Alisa Decor & Balloons — сайт

Главная страница студии декора и воздушных шаров в Комрате.

- `index.html` — страница сайта
- `img/` — фото работ, видео первого экрана и миниатюры (`img/t/`)

Сайт публикуется через GitHub Pages из ветки `site`.

## Ветка `crm` — мини-CRM

В этой ветке к сайту добавлены приём заявок через сервер (Supabase и Telegram) и закрытая панель `/admin`.
Как подключить — в [docs/CRM-SETUP.md](docs/CRM-SETUP.md).
